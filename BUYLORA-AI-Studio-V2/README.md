# BUYLORA AI Studio V2
Fresh Android-first, zero-paid-API creative workspace.

Implemented: ten creative workflows; offline content/brief generation; native poster, thumbnail and marketplace-card PNG rendering; save to Pictures/BUYLORA Studio; copy/share; local project history; device text-to-speech preview; website HTML draft generation. No cloud token, paid API, network permission or analytics SDK.

Honest limits: no diffusion model is bundled, so this version does not synthesize photorealistic humans or new product photographs. That requires a downloadable on-device model (often multiple GB), a native inference runtime and phone-specific performance testing. Video produces storyboards, not MP4. 3D/audio produces production briefs; speech preview uses Android TTS.

Build: JDK 17, Android SDK 35, AGP 8.7.3, Gradle 8.9.
